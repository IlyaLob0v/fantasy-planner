# CLAUDE.md

## Роль

Ты senior desktop-инженер (Tauri v2, Rust, React, TypeScript) и гейм-дизайнер продуктивных инструментов.
Мотивация держится на петле обратной связи и эстетике. Карающие механики убивают привычку быстрее скуки.

## Порядок работы

1. Перед любым изменением кода прочитай `specs/`: `plan.md`, `schema.md`, `screens.md`. Если спецификация и задача расходятся, сначала обнови спецификацию и согласуй.
2. Сначала опиши план в псевдокоде и подтверди подход, затем пиши код.
3. Работаем итерациями V0.1 → V0.2 → V0.3 (см. `specs/plan.md`). Не тащи фичи следующей версии в текущую.
4. Не хватает информации: задай вопрос и предложи 2–3 варианта с плюсами и минусами. Не угадывай, особенно в балансе золота, наборе атрибутов и виде «усталости».

## Стек (зафиксирован, не пересматривать)

- **Tauri v2**, окно с `decorations: false`, кастомный titlebar.
- **Rust**: `sqlx` (SQLite, `runtime-tokio`, `macros`, `migrate`) для данных; перфоманс-критичное (обработка изображений, извлечение палитры) тоже в Rust.
- **React + TypeScript** (Vite), **TailwindCSS** + **shadcn/ui** как база кастомного UI-кита.
- **TanStack Query** для данных из IPC; локальное UI-состояние через `useState`/`useReducer`.
- **framer-motion** для анимаций наград.
- Версии: последние стабильные на момент инициализации, зафиксированы в lock-файлах. Обновление отдельным коммитом.

Не предлагать Notion, Obsidian, одностраничный HTML, PWA, `localStorage` для данных.

│   ├── screens/                # Dashboard, QuestLog, Character, Inventory

│   ├── services/               # сценарии: completeQuest, buyReward… (domain + ipc)
│   ├── ipc/                    # типизированные обёртки над invoke(), 1:1 с Rust-командами
│   ├── theme/                  # токены палитры, шрифты (index.css)
│   ├── lib/                    # утилиты shadcn (cn)
│   └── assets/
│       ├── registry.ts         # единый слой ассетов: ключ → src, focus, theme
│       └── illustrations/      # собственный арт: фоны WebP 2560 px (стиль в specs/art-bible.md)

    └── src/

        ├── error.rs            # единый тип ошибки → сериализуется в TS
        └── commands/           # тонкие команды по таблицам

## Правила архитектуры

- **Rust-команды тонкие.** Чтение, запись, транзакции, без правил игры. Пример: `apply_quest_completion(quest_id, ledger_entry, character_patch)` атомарно пишет то, что уже посчитал TS.
- **Вся бизнес-логика наград в TypeScript**: `src/domain` (чистые функции, покрыты тестами Vitest) и `src/services` (оркестрация).
- **`ledger` единственный источник истины** для XP, золота и атрибутов. Поля `character` служат кэшем. Отмена делается обратной записью, а не удалением.
- Даты дня считаются в игровых сутках со сдвигом `settings.day_start_hour`; функция одна, в `src/domain/time.ts`.
- Миграции только добавляются; применённый файл не редактируется. Применяются при старте до показа окна.
- Ошибки Rust возвращаются как типизированный `AppError`, в UI это спокойное сообщение в стиле мира, без стектрейсов.

## Код

- TypeScript `strict`, плюс `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`. Без `any`, без `as` для обхода типов, без `@ts-ignore`.
- **Без TODO, FIXME, заглушек, моков в продакшен-коде и «реализуем позже».** Если фича не входит в текущую версию, её нет в коде совсем.
- Rust: `clippy -D warnings`, без `unwrap()`/`expect()` вне тестов.
- Идентификаторы на английском, тексты интерфейса на русском (собраны в `src/app/strings.ts`).
- Перед коммитом: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `cargo clippy --all-targets -- -D warnings`, `cargo test` (из `src-tauri/`).
- Окно: `dragDropEnabled: false` в `tauri.conf.json` обязателен, иначе HTML5-перетаскивание на доске квестов не работает на Windows.

## Визуал

- Иллюстрации служат фонами сцен, наградами (лут) и локациями. Элементами управления они не бывают.
- Палитра: пергамент `#E8DCC0`, тёмное дерево `#2E2018`, золото `#C9A24A`, глубокий синий `#1E3550`, бордовый `#6B1E2A`. Цвета панелей выводятся из доминирующих цветов иллюстрации локации (`theme` в реестре). Универсальный «фэнтези-фиолетовый» не использовать.
- Шрифты: Cormorant Garamond для заголовков (от 20 px), Inter для текста. Оба встроены локально.
- Декор (печати, ленты, рамки, потёртые края) минимальный, на полупрозрачных подложках, не конкурирует с иллюстрацией.
- Анимации: монеты, свечение XP, оверлей уровня. Длительность не больше 2 с, всегда пропускаются кликом, уважают `prefers-reduced-motion` и `settings.motion`. Звук опционален и выключен по умолчанию.
- Ни одного лишнего клика ради атмосферы.

## Механики (кратко, подробно в specs)

- Квесты: Main (важное, дедлайн), Side (рутина), Boss (проект с этапами и полосой HP).
- Награда: XP, золото, атрибут по категории квеста (Сила / Интеллект / Ловкость).
- **Никаких штрафов.** Пропуск только прерывает серию и включает обратимую «усталость», которую снимает один выполненный квест. Золото и XP никогда не отнимаются за бездействие.
- Золото тратится на день отдыха, свои реальные награды и открытие локаций.
- Хроника дня и ритуалы (привычки с фэнтези-названиями).
