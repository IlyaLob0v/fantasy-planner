# Иллюстрации

Растровые фоны в WebP, 2560 px по ширине. Сейчас здесь живопись XIX века в общественном
достоянии с Wikimedia Commons; автор, год, лицензия и ссылка на источник записаны в `credit`
каждого ключа в `src/assets/registry.ts`.

| файл | ключ | картина |
|---|---|---|
| `castle-departure.webp` | `location.gatehouse` | Томас Коул, «Отъезд», 1837 |
| `pine-forest-morning.webp` | `location.forest` | Иван Шишкин, Константин Савицкий, «Утро в сосновом лесу», 1889 |
| `wanderer-fog.webp` | `hero` | Каспар Давид Фридрих, «Странник над морем тумана», 1818 |
| `monastery-cellar.webp` | `treasury` | Эдуард фон Грютцнер, «В монастырском погребе», 1878 |

Чтобы заменить арт, положи файл сюда, импортируй его в реестре вместо прежнего `src` и
обнови `focus` (точку, которая не должна обрезаться), `theme` (цвета панелей из доминирующих
цветов картины) и `credit`. Код экранов менять не нужно.
