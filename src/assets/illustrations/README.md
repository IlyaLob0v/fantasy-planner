# Иллюстрации

Собственный арт проекта: сгенерирован в Leonardo.ai (модель Lucid Origin) по промптам из
`specs/art-bible.md`, увеличен Real-ESRGAN ×2, отретуширован (убраны псевдоподписи и надписи)
и сохранён в WebP 2560 px по ширине.

| файл | ключ | сцена |
|---|---|---|
| `gatehouse.webp` | `location.gatehouse` | Надвратная башня гильдии, дозорные на стене |
| `forest.webp` | `location.forest` | Лагерь следопытов в сосновом бору |
| `tavern.webp` | `location.tavern` | Таверна «Пьяный грифон» |
| `goblin-market.webp` | `location.goblin_market` | Гоблинский рынок на болоте |
| `dragon-lair.webp` | `location.dragon_lair` | Логово дракона в старой шахте |
| `hero.webp` | `hero` | Рыцарь-странник над морем облаков |
| `treasury.webp` | `treasury` | Казна гильдии с гоблином-слугой |

Чтобы заменить арт, положи файл сюда, импортируй его в реестре вместо прежнего `src` и
обнови `focus` (точку, которая не должна обрезаться), `theme` (цвета панелей из доминирующих
цветов картинки) и `credit`. Код экранов менять не нужно.
